# Frontend Builder

Prosty frontend w React z Tailwind CSS.

## Wymagania

- Node.js >= 16
- npm >= 8

## Instalacja

1. Sklonuj repozytorium i przejdź do folderu frontendu:

```bash
cd front-builder
Zainstaluj zależności:

bash
Skopiuj kod
npm install
Uruchom serwer deweloperski:

bash
Skopiuj kod
npm start
Frontend będzie dostępny pod adresem: http://localhost:3000

Budowanie produkcyjne
Aby przygotować frontend do wdrożenia:

bash
Skopiuj kod
npm run build
Pliki produkcyjne zostaną zapisane w folderze build.

javascript
